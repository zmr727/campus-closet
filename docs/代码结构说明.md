## 三、后端 PHP `campus_api/`（已按业务分子目录）

```
campus_api/
  config.php / ping.php / upload_cover.php   ← 公共（留在根目录）
  uploads/                                  ← 上传图片
  user/          登录与用户资料
  clothes/       服装
  order/         订单与评价
  favorite/      收藏
  message/       消息
  buyershow/     买家秀
  vip/           会员
  seed/          种子数据（浏览器打开灌库）
  sql/           建表参考 SQL
```

小程序请求路径示例：`/user/login_phone.php`、`/clothes/list_clothes.php`

| `upload_cover.php` | 上传封面/头像 |

## 六、建议过代码顺序（约 1 小时）

1. `utils/request.js` → `config.php` → `ping.php`  
2. 登录：`login` → `auth` → `phone` → `user/login_*.php`  
3. 首页列表：`index` → `clothes/list_clothes.php`  
4. 发布闭环：`rentForm` → `clothes/create|update|delete_clothes.php` → `myPublish`  
5. 下单与核销：`detail` → `order/create|pay|advance_order` → `orders`  
6. 互评：`review` / `order/submit_review` → 详情评价 / `myReviews`  
7. 收藏 / 消息 / 资料各抽一条链路看一遍
